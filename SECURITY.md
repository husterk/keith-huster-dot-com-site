# Security

This repository holds the source of a personal website. It contains no secrets: credentials live in 1Password and are injected at deploy time (see `docs/plan/03-ci-cd-and-secrets.md`).

If you find a security issue (for example in the contact endpoint), report it privately through GitHub: open the **Security** tab and choose **Report a vulnerability**. If that isn't possible, email husterk@gmail.com. Please don't open a public issue. I'll acknowledge within a few days.
